Secret Santa randomizer

Add your participants and their codes. You get a random list showing which code each Santa receives. It all runs in your browser and nothing is uploaded or saved.

1. Participants

Codes are shown in capitals. Names only, with no code column, also works if you tick the box below.

Optional: fixed assignments

These are kept exactly. Everyone else is randomized around them.

2. Your private master list

Keep this to yourself. It shows who gives to whom. Nothing is saved, so download what you need before you close or refresh this page.

    SantaRecipientCode to send to Santa

    3. Send each Santa their code

    Each message contains only that Santa's own recipient code.

    Some names contain characters the PDF can't draw (accents or non-English letters). They are simplified or dropped in the PDF cards. The list and messages keep them as typed.

    4. Reveal link (for later)

    When it's time to reveal, share this one link with everyone. Each Santa enters the code you sent them and sees who they are gifting. The link holds only names and codes, never who gives to whom, so it is safe to share when you choose.
